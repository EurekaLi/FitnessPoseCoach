实验日期2026-10-17，整理日期2026-10-30。以下摘自本地报告，不代表CI重新运行真实数据评估。

## 独立测试

RepCount-A三类已知来源子集：训练可用190段、验证46段、测试61段（深蹲18/俯卧撑19/开合跳24）。不是官方test60段，也不是已核实的跨人物独立评估。来源不明77段排除，同来源按test>valid>train重新分组。

| 指标 | 结果 |
| --- | ---: |
| 整段视频分类准确率 | 100%（61/61） |
| 原始窗口准确率 / 宏F1 | 96.97% / 96.73% |
| 在线ready覆盖率 | 80.74% |
| ready时刻整段标签一致率 | 98.70% |
| 计数MAE | 9.54次/视频 |
| 误差不超过1次 | 15/61 |
| 深蹲 / 俯卧撑 / 开合跳MAE | 3.00 / 12.95 / 11.75次 |

整段分类按窗口概率平均，不是实时每个时刻的准确率。ready表示当前输入可用且动作已确认，必须同时看覆盖率；整段标签不是精确逐帧标注。计数不补预热/缺失动作，不删除困难视频。

原件在outputs/independent_test_v6/evaluation/report.json，不随Git分发；本摘要不能替代原始材料。测试后没有据此继续挑模型或调计数阈值。

## 转换与工程验证

- 122个验证窗：PyTorch CPU与ORT CPU类别全部一致，最大logit差4.7684e-6；Windows CUDA最大差2.8610e-6。
- 三段完整Windows GPU骨架回放：动作、状态、事件与参考一致，次数为5/10/0，0也保留，不把一致性当作计数准确。
- 公开验证视频80点检测→姿态→动作→计数连接检查通过，无窗口模式、不打开真实相机、不保存影像。
- CPU基础测试28项，部署测试7项；输入为合成数据，不需权重。

TensorRT只做了环境与微型引擎构建/加载检查，真实模型FP16推理和加速尚未完成。没有公布摄像头端到端FPS、加速倍数或专业动作纠错效果。
